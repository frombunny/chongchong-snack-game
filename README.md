# 총총 · 몰래 먹는 과자 시간!

[게임 플레이](https://frombunny.github.io/chongchong-snack-game/)

총총 부스용 3D 미니게임입니다. 바니·이든·피즈·디움·안톨리니 몰래 30초 안에 과자 18개를 먹으면 성공!

- 참가자 닉네임(최대 12자)을 입력하고 시작합니다. 결과에 닉네임·먹은 과자 개수·플레이 시간(초)이 표시됩니다. 일시정지는 시간에서 제외하며, 다음 참가자는 닉네임을 바꿔 시작할 수 있습니다.
- 스페이스바 또는 분홍 버튼을 누르는 동안 먹습니다. 놓으면 숨깁니다.
- 다섯 명이 각자 랜덤으로 돌아봅니다. 예고는 0.5~0.75초, 다시 보기까지 간격은 3.2~8초입니다. 감시가 겹칠 수 있습니다.
- 한 명이라도 보고 있을 때 먹으면 들킵니다.
- 드래그와 시점 버튼으로 3D 방을 둘러볼 수 있습니다. 소리 끄기와 자동 일시정지를 지원합니다.

## 파일

`index.html`은 3D 엔진·폰트·음원을 포함한 실행용 파일입니다. 다운로드 후 브라우저에서 열어도 실행됩니다. GitHub Pages는 `main` 브랜치 루트를 게시합니다.

## 외부 구성 요소

Three.js 0.180.0 및 RoundedBoxGeometry는 MIT, Pretendard와 Gaegu 글꼴은 SIL Open Font License를 따릅니다. 관련 고지는 `licenses/`와 HTML에 포함되어 있습니다. 과자 소리는 제작자가 제공한 음원입니다.

## 검증

게시 전 게임 로직 자동 테스트에서 과자 감소·들킴·시간 초과·일시정지와 예고 시작 후 300ms 안에 손을 떼는 전략으로 40판 중 27판 클리어와 정상 시간 초과를 확인했습니다. 실제 휴대폰·현장 스피커는 별도 확인이 필요합니다.

## 공유 순위표와 배경음악

게임 아래에 모든 참가자의 상위 20개 기록을 표시합니다. 먹은 과자가 많은 순, 같으면 플레이 시간이 짧은 순입니다. 같은 닉네임은 최고 기록 하나만 순위표에 표시합니다. 결과 기록은 Supabase 무료 DB에 저장되며 네트워크 오류 시 다시 저장할 수 있습니다.

직접 만든 실로폰풍 BGM이 플레이 중 재생됩니다. 일시정지·종료하면 멈추고 상단 소리 버튼으로 음소거할 수 있습니다.

순위 데이터에는 RLS와 입력 제약이 적용되며 공개 클라이언트의 수정·삭제는 허용하지 않습니다. 클라이언트 제출형 점수이므로 완전한 부정행위 방지는 제공하지 않습니다.

게임 결과창에서 저장 직후 닉네임별 최고 기록 기준 내 순위를 표시합니다. 개수·시간이 같으면 먼저 저장된 기록이 앞섭니다. 연결 실패 시 같은 판을 중복 저장하지 않고 다시 확인할 수 있습니다. 순위는 확인 시점 기준입니다.

여러 명이 감시하거나 마지막 8초가 되면 낮은 심장박동과 긴장 안내가 나옵니다. 들키면 다섯 캐릭터가 약 2.4초간 만화식 발 구르기·주먹·별·퍽 효과를 보여 준 뒤 결과창을 엽니다. 시점이 뒤로 기울고 발과 주먹이 번갈아 다가옵니다. 움직임 줄이기 설정에서는 반복 동작을 줄입니다. 최고 기록 선정·동점 시간 비교·기록 갱신은 DB 트랜잭션 회귀 테스트로 검증했습니다.

들킴 연출을 2.4초로 늘리고 카메라의 좌우·상하 흔들림과 기울기를 강화했습니다. 성공·시간 초과 결과 대기는 1.1초를 유지하며 연출 시간은 순위 기록 시간에 포함하지 않습니다.

동시 감시 강화: 각자 보는 시간은 1.3~2.1초, 다음 예고까지 간격은 3.2~8초입니다. 동일한 100개 난수 시드에서 2명 이상 동시 감시 시간이 판당 평균 4.79초에서 6.98초로, 3명 이상은 0.95초에서 1.78초로 증가했습니다. 예고 후 300ms 반응 전략의 클리어는 99/100에서 84/100으로 바뀌었습니다. 실제 사람의 성공률을 뜻하지 않습니다.

3~4명 동시 감시 강화: 같은 100개 시드에서 3명 이상 겹치는 시간이 평균 1.78초 → 2.72초, 4명 이상이 겹치는 판은 45판 → 65판으로 증가했습니다. 예고 후 300ms 반응 전략의 성공률은 84/100 → 67/100입니다. 이는 자동 시뮬레이션 결과이며 실제 사람의 성공률은 아닙니다.

들킴 연출 보정: 카메라 앞의 분리된 발·주먹 대신 다섯 캐릭터 전체가 약 0.38초 동안 앞으로 이동하고, 몸에 붙은 발로 번갈아 점프·착지합니다. 플레이어 시점은 바닥 가까이 내려갑니다. 결과 화면과 재시작 시 원래 위치·크기로 복원합니다. 애니메이션 QA는 순위 제출을 막은 상태로 수행합니다.
